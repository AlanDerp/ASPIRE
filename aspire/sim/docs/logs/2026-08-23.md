# Knowledge consolidation engineering log — 2026-08-23

- Closed the direct overlay activation path. `forest save-edge` was removed;
  the public workflow is now `overlay propose` → `overlay review` → `overlay
  promote`.
- Overlay proposals lock exact source and target revisions plus a frozen
  checkpoint. Review additionally binds the proposal hash and an exact
  development base manifest, and its content is retained as a content-addressed
  repository artifact; promotion appends a revision-specific lifecycle event.
- Actor retrieval, overlay projections, manifest validation, and the rebuildable
  SQLite index now fail closed unless edge status, review evidence, endpoint
  revisions, and promotion event agree exactly.
- Added negative tests proving proposals and mismatched promotion events remain
  invisible, plus a real CLI round trip through a promoted edge and newer active
  manifest.
- Active revision selection now filters reviewed/promoted revisions before
  choosing the newest version, so a newer proposal cannot shadow an older active
  edge. Validation shares one revision/manifest/event snapshot per resolution
  instead of rescanning the growing repository once per edge.
- No simulator, GPU, held-out benchmark, or human research evidence was created
  by this engineering change. The research claim remains not evaluable and the
  justified runtime default remains `off`.
- Rebuilt controlled stress generation as cumulative prefix-stable snapshots;
  the eight stress kinds now apply distinct AST/contract transformations rather
  than labels over identical code.
- Added a hash-validating synthetic-only repetition audit for each scale and
  made preregistration lock an existing audit path/hash for every organic and
  synthetic checkpoint. Synthetic source outcomes remain inherited control
  labels and cannot authorize evidence, canonicalization, principle support, or
  promotion.
